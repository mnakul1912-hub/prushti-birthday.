PRUSHTI BIRTHDAY WEBSITE
========================

FILES
- index.html: the complete mobile-first birthday website
- assets/music.mp3: optional background music file (add your own licensed/permission-cleared MP3)

HOW TO PREVIEW ON ANDROID
1. Extract the ZIP file.
2. Open index.html with a browser, or use an HTML preview app.
3. The birthday countdown is set to 13 October 2026.
4. Tap each photo frame to preview a photo locally in that browser. These photo previews are not saved into the website and are not uploaded.
5. For music, place your MP3 at assets/music.mp3. Browsers require a tap before audio starts.

HOW TO PUBLISH A SHAREABLE LINK WITH GITHUB PAGES
1. Sign in to GitHub or create an account.
2. Create a new PUBLIC repository, for example: prushti-birthday.
3. Upload index.html and the assets folder (including music.mp3 if you add it).
4. Open repository Settings > Pages.
5. Under Build and deployment, choose "Deploy from a branch".
6. Choose branch "main" and folder "/ (root)", then Save.
7. Wait for deployment. GitHub Pages will show a public URL similar to:
   https://YOUR-USERNAME.github.io/prushti-birthday/
8. Open that URL on your phone to test it, then share the link with Prushti.

ALTERNATIVE: NETLIFY DROP
1. Open https://app.netlify.com/drop in your browser.
2. Sign in if prompted.
3. Drag the extracted website folder into the drop area (or use the upload control if shown).
4. Netlify will provide a public URL. Test it on your phone before sharing.

PERSONALIZATION
- Edit the letter, timeline memories, secret message, and signature in index.html.
- Use photos that you have permission to share.
- This site does not upload photos selected in the gallery; they only preview in the current browser session.
- Background music is not bundled because no song was specified. Add a licensed MP3 as assets/music.mp3.
